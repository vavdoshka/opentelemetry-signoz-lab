Search query reference

Every query here was run against this lab, and its real result is saved with it. Each one says which lab it is for, because the two labs use different service names. Use Run live to run it again now. Start load first if you want recent data.

Time range comes first

An empty result usually means the wrong time range, not a bad query. The Explorers default to the last 30 minutes. If you have not fired a scenario in that time, or if load is stopped, widen the range. Run live uses the window stated in each result.

Search expression syntax

Each operator was run with the example shown, and returned rows. Quote strings with single quotes. Attribute names are the OpenTelemetry names, such as http.route. These examples work in any lab, so add a service.name filter to narrow one down: Lab 1 uses lab1-frontend and lab1-backend, and Lab 2 uses frontend and backend.

Fields you will use most

FieldOnNote
service.nameSpans, logsBlank on stdout log copies (gap 4)
trace_idSpans, logsThe link between the two
k8s.pod.nameSpans, logsAdded by the agent on the node
nameSpansThe operation, such as GET /work/slow
http.targetSpansThe URL path, such as /api/scenario/crash. Tells Lab 1's scenarios apart.
duration_nanoSpansNanoseconds: one second is 1000000000
has_errorSpansTrue when span status is Error. It also matches ASGI http send spans, so counts run high.
kind_stringSpansServer, Client or Internal
response_status_codeSpansCompares numerically. Empty on non-HTTP spans.
bodyLogsThe log message
attribute.order.totalLogs, spansInside an aggregation, as in sum(attribute.order.total). In a filter, write order.total.
severity_textLogsINFO, WARN, ERROR. Note it is WARN, not WARNING.

Traces, what to count: has_error = true matched 1,013 Lab 1 spans in the load run, but 383 of those were http send copies. Only 383 were Server spans. Add kind_string = 'Server' if you want to count failed requests.
